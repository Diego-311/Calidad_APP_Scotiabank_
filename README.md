# Calidad APP Scotiabank

Aplicación web de demostración para flujos de banca digital, desarrollada con React, TypeScript, Vite y Tailwind CSS. Los datos son simulados; no es una aplicación oficial ni debe utilizarse para operaciones bancarias reales.

## Requisitos

- Node.js 22 o una versión compatible con Vite 8.
- npm.

## Instalación y ejecución

1. Descomprime el proyecto y abre una terminal en la carpeta `Calidad_APP_Scotiabank-main`.
2. Instala las dependencias: `npm install`.
3. Inicia el servidor de desarrollo: `npm run dev`.
4. Abre la URL local que indique Vite (normalmente `http://localhost:3000`).

## Comprobaciones

- `npm run lint`: comprueba los tipos TypeScript.
- `npm run build`: comprueba los tipos y genera la versión de producción en `dist/`.

No se requiere una clave de Gemini para ejecutar la interfaz actual, ya que el proyecto utiliza datos simulados locales.
